# deep-learning-image-classifier

**Deep learning with small data**

Built a convolutional neural network (CNN) image classifier during Jeremy Howard's Practical Deep Learning for Coders (fast.ai). The model distinguishes between two types of snowmen: Olaf from Disney's *Frozen* (friendly) and the abominable snowman (not friendly, run).

Trained on just ~150 images per class using transfer learning. The goal: show that you don't need a large dataset to build an accurate classifier, and make AI tangible and fun for kids.

No children were harmed in training or testing this CNN! But we may have tricked them into learning a bit about AI. ;)

**Technologies:** Python, fast.ai (built on PyTorch)  
**Technique:** Transfer learning  
**Base Model:** ResNet-18, pre-trained on ImageNet  
**Dataset:** ~150 images per class, sourced via DuckDuckGo image search

## Approach

ResNet-18 was chosen because it's one of the smallest CNN architectures, well suited for a small dataset. Traditionally this kind of image classification required collecting thousands of labeled examples. Transfer learning changes the equation: start with a model that already understands visual features, freeze early layers, train the head for one epoch, then unfreeze and train all layers.

## Limitations

The classifier was trained on two classes only. It may recognize permutations (e.g., Olaf's features on a toilet paper roll) but may not generalize to other types of snowmen.
